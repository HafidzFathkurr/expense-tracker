# 💰 Expense Tracker

Aplikasi catatan keuangan harian sederhana untuk mencatat pemasukan dan pengeluaran.

## Teknologi

- HTML
- CSS
- JavaScript (Vanilla)
- LocalStorage

## Fitur (rencana)

- [ ] Tambah pemasukan
- [ ] Tambah pengeluaran
- [ ] Hitung total saldo otomatis
- [ ] Riwayat transaksi
- [ ] Edit transaksi
- [ ] Hapus transaksi
- [ ] Filter berdasarkan kategori
- [ ] Penyimpanan dengan LocalStorage
